# 语雀复现功能要求清单（28 条）

来源：人工组织，2026-08-27。用于评审 AI Agent 复现的语雀工作台网页。

1. 多入口内容创建编排：首页 → 新建文档 / 知识库 / 模板 / AI → 不同创建流程 → 创建结果进入正确上下文
2. 文档编辑与持久化闭环：创建文档 → 编辑标题/正文 → 自动或手动保存 → 离开 → 再进入 → 内容保持
3. 模板实例化与内容隔离：模板中心 → 选择模板 → 生成文档 → 修改新文档 → 原模板不受影响
4. 知识库创建与初始化：新建知识库 → 配置信息 → 可见性/类型 → 创建 → 自动进入知识库 → 可继续创建内容
5. 小记快速捕获与发布：输入即时内容 → Ctrl+Enter/按钮发布 → 新小记出现 → 输入区复位 → 刷新仍存在
6. 知识层级组织与导航：用户空间 → 知识库 → 目录/分组 → 文档 → 通过层级路径返回
7. 文档归属迁移与路径同步：文档属于知识库 A → 调整归属 → 移至知识库 B → 首页/路径/搜索结果同步更新
8. 行为驱动的内容聚合：阅读/编辑/点赞/评论某文档 → 首页「浏览过/编辑过/点赞过/评论过」动态出现对应内容
9. 多维组合筛选：类型 → 归属 → 创建者 → 多条件组合 → 删除某条件 → 结果实时重新计算
10. 全局知识搜索与召回：输入关键词 → 搜索多个知识对象 → 排序/筛选 → 点击结果 → 定位正确资源
11. 导航上下文与列表状态恢复：设置 Tab/筛选/滚动位置 → 打开文档 → 浏览器返回 → 原状态完整恢复
12. 点赞行为跨系统同步：用户 B 点赞文档 → 文档点赞状态变化 → 作者侧收到对应影响 → B 取消点赞 → 各处同步撤销
13. 评论与 @ 协作闭环：评论文档 → @某用户 → 内容记录 → 被 @ 用户收到消息 → 点击消息定位对应讨论
14. 跨类型收藏聚合：收藏文档/表格/其他知识对象 → 收藏页统一呈现 → 点击恢复到原始对象
15. 收藏组织、排序与双向状态：收藏对象 → 按名称/收藏时间排序 → 从收藏页取消 → 原对象收藏 Icon 同步变化
16. 业务事件驱动通知生成：点赞/评论/关注/系统事件发生 → 根据事件类型生成不同通知 → 进入对应分类
17. 未读/已读通知状态机：新通知产生 → 未读列表 → 打开通知 → 状态变为已读 → 已读 Tab 可找到
18. 通知分类与计数联动：全部消息 / 点赞 / @评论 / 待处理 / 系统通知等分别计算数量 → 单条已读后多处计数同步
19. "全部已读"批量状态同步：多分类存在未读 → 点击全部已读 → 所有通知更新 → 顶部 badge、分类数字、Tab 同步刷新
20. 可操作通知与访问申请工作流：用户申请访问私有知识库 → Owner 收到待处理 → 查看 → 批准/拒绝 → 权限变化 → Applicant 得到结果
21. 通知 Deep Link 与业务上下文恢复：点击点赞/评论/访问申请通知 → 跳至具体文档/知识库/审批页 → 返回消息中心仍保留上下文
22. 花园公开/私密发布状态：花园 Private → 其他用户不可访问 → Owner 设置 Public → 外部访问可见 → 再关闭后立即失效
23. 公开知识内容选择性策展：私有知识库很多 → 选择部分加入公开花园 → 外部只看到被公开的内容 → 移除后消失
24. 个人主页与社交关系聚合：个人信息 + 自定义介绍 + 关注/粉丝 + 公开知识库 + 活跃度组合成个人主页
25. 创作数据动态聚合：创建/编辑文档、小记 → 创作天数、创作字数、内容更新等指标重新计算
26. 知识资产结构统计：文档/知识库/小记变化 → 「X 文档 / Y 知识库 / Z 小记」等数据动态变化
27. 互动数据与作者统计联动：他人阅读/点赞/评论/收藏 → 作者侧阅读量、点赞量、评论量、互动用户统计更新
28. 时间序列创作指数 / Heatmap：每日创建、编辑、发布行为 → 聚合到日期 → 生成年度活跃度 Heatmap → 日期切换仍正确
29. 配置、权限与运行时行为联动：修改消息/提醒/权限等设置 → 后续真实业务事件遵循配置
