---
name: self-built-explorer
description: 在隔离空白环境中，以纯黑盒、类人方式认真探索未知网站并复现其核心功能。
---

在隔离环境中尽可能认真、充分地探索未知网站，理解其可观察的核心功能。目标浏览器
已经由隔离环境启动，可通过 `begin_workspace` 返回的浏览器 I/O 根位置访问；工作区中
没有也不需要另行启动浏览器。该接口只连接目标浏览器的可见像素与类人输入，不提供
现成操作工具、工具实现、页面语义、探索流程或输出规范。
起始 URL 是任务必须明确提供的入口：如果用户没有给出，先向用户索取，不得自行猜测
或使用默认目标。收到后，开始时调用一次 `begin_workspace` 并把它原样作为
`target_url` 传入；完成时调用 `finish_workspace`。该 URL 不是后续导航白名单：目标
流程发生重定向、换域、打开新页面或经多个 URL 串联时，应继续按可见结果探索。

严格限制：

- 只能使用 `blackboxbench-self-built` 提供的隔离工作区操作；不得使用工作区之外的
  文件、程序、服务或信息来源。
- 不得读取目标源码、页面源码、DOM、Accessibility tree、selector、接口响应、网络
  请求、Cookie、存储或其他网页语义通道；不得搜索、下载或复用原始实现，也不得接触
  本项目其他探索条件的实现或产物。
- 起始 URL 只用于指定隔离环境最初打开的网页。允许目标浏览器在真实可见流程中加载
  依赖资源、自动重定向以及通过类人操作到达其他 URL；不得因为地址或域名变化而停止。
- 工作区可能具备普通网络能力，但网络只能用于取得与目标无关的通用依赖。
  不得直接请求目标或关联站点，不得搜索目标及其原始实现，不得下载网页、页面源码、
  接口响应或站点素材，也不得把任何网络检索结果作为探索结论。对目标的判断仍只能
  来自隔离环境中的可见结果。
- 探索必须保持纯黑盒和类人操作；对目标的认知只能来自屏幕上实际可见的结果。
- 不得凭空捏造或依据训练数据、先验知识、公共素材猜测目标功能；复现只能依据本次
  真实探索所得。未进行真实探索时禁止生成网站，并必须明确报告失败。
- 目标网页可能显示真实账号的私人信息；这些内容不属于复现目标。复现时不得复制或
  硬编码真实姓名、账号、文档标题、正文、评论、消息等私人内容，只复现实际观察到的
  页面结构与功能，并使用复现环境提供的公共虚构素材替代私人数据。
- 工作区内容必须完全来自你自己的探索；定稿时会与基准私有内容比对，任何来源
  不明的内容都会导致 `finish_workspace` 被拒绝。

当你独立判断已经进行了尽可能认真、充分的探索后，调用 `finish_workspace`。
如果返回的 `stage` 为 `reproduction`，则依据本次真实探索所得，在当前隔离环境中
复现目标网站的核心功能；不得补写未经探索的目标行为。完成后再次调用
`finish_workspace` 结束任务。
