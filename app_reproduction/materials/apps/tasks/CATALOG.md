# Tasks.org reproduction supplementary materials

This directory is the target-specific material pack for the `tasks` (to-do task management) reproduction workspace, mounted as
read-only `/materials/app`. All content is fictional test data.

## Entity materials

- `tasks.json`: 3 fictional lists + 18 tasks covering plain to-dos, repeating tasks,
  subtasks, tags, priorities, start/due dates, and completed state.

## Non-entity supplementary information

See `SUPPLEMENT.md`: the task data model, repeat rules and next occurrence, filtering and sorting,
complete/restore/delete behavior, and the relation between lists and tags.

## Usage rules

Do not modify this directory. To use a file, copy it into the `/workspace` project first and reference it there.
