# Tasks.org 复现补充信息（非实体素材）

## 任务数据模型

| 字段 | 说明 |
|---|---|
| 标题 / 备注 | 必填 / 可选 |
| 列表 | 归属的任务清单（工作/生活/购物…） |
| 截止日期 | 可含时间；可选「开始日期」形成区间 |
| 重复 | 完成后按规则生成下一次出现 |
| 优先级 | 高/中/低（0=无），影响排序与视觉标记 |
| 标签 | 多值，跨列表横向归类 |
| 子任务 | 两级嵌套；父任务完成不强制子任务完成 |
| 完成状态 | 完成时记录完成时间；可恢复 |

- 快捷日期选项：今天 / 明天 / 下周日 / 无日期。

## 重复规则与下一次出现

- 完成重复任务时，当前实例标记完成，**同一条目上立即生成下一次出现**
  （不是新建一条，而是同一任务的下一个实例），按规则顺延：

| 规则 | 下一次出现 |
|---|---|
| 每天 | 明天同一时间 |
| 每周（周一） | 下一个周一 |
| 每月 15 日 | 下月 15 日 |
| 逾期完成 | 从完成日顺延，不补漏掉的实例 |

## 筛选与排序

- 列表筛选：按列表查看；「隐藏已完成」开关把完成项从列表移除，
  数据仍在（关闭开关可见）。
- 排序：按截止日期 / 优先级 / 标题 / 手动拖动，升降序可切。
- 标签页：点标签看到跨列表的同类任务。

## 完成 / 恢复 / 删除

- 勾选完成 → 打勾 + 完成时间戳，默认移到底部或按设置隐藏。
- 恢复：取消完成，回到未完成区。
- 删除：从列表消失；删除后不参与任何筛选与统计。

## 复现行为要点

- 列表页（含徽标：未完成数）、任务详情、新建/编辑表单、筛选器四个
  核心界面完整。
- 「隐藏已完成」切换后已完成项消失但数据保留，再切回可见。
- 重复任务完成后新实例立即出现且日期正确。
- 全部写操作重启后保持。
