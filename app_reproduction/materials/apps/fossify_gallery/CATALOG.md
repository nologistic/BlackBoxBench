# Fossify Gallery reproduction supplementary materials

This directory is the target-specific material pack for the `fossify_gallery` (image/video gallery) reproduction workspace,
mounted read-only as `/materials/app`. This pack is mainly non-entity information.

## Entity materials

- No target-specific entity materials. Album content reuses `/materials/mobile/images/` (avatars/
  products/covers/social) plus the fictional media in `/materials/mobile/video/` and `file_picker/`;
  grouping by fictional directory names is enough to form multiple albums.

## Non-entity supplementary information

See `SUPPLEMENT.md`: album aggregation rules, the 30-day recycle bin, .nomedia hiding,
favorites and sorting, the built-in editor, and the security lock / privacy protection.

## Usage rules

Do not modify this directory.
